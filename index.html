Rather than just saying "change the font size", I'll show you where to look because as the app grows you'll want one place to control the typography. 1. Open index.html Search (Ctrl/Cmd + F) for: .hero-title or .current-title Depending on which version you're on, you'll see something similar to: .current-title{ font-size:72px; font-weight:900; line-height:.9; } or .hero-title{ font-size:5rem; } Change: font-size:72px; to something like font-size:84px; or font-size:96px; 2. The logo Search for .logo or .brand You'll likely find .logo{ font-size:92px; } Increase that to font-size:110px; or whatever looks right. 3. Body text Search for .current-body or .thing-body You'll see something like .current-body{ font-size:20px; } Change that to font-size:22px; or font-size:24px; 4. Stack names Search .stack-name Usually something like .stack-name{ font-size:18px; } You could make these font-size:22px; font-weight:700; 5. The BEST way (what I recommend) Rather than hunting through CSS every time, create variables at the top of your stylesheet. Something like: :root{ --logo-size: 110px; --hero-size: 92px; --body-size: 24px; --stack-size: 22px; --label-size: 14px; } Then instead of font-size:92px; use font-size:var(--hero-size); Now if you want to make every task title bigger, you change one number: --hero-size:100px; Everything updates instantly. Even better... As we're rebuilding One More Thing, I'd love to make typography one of the app's superpowers. Imagine at the top of your CSS having something like: /* TYPOGRAPHY */ :root{ --display:clamp(72px,8vw,140px); --title:clamp(42px,5vw,88px); --heading:28px; --body:22px; --small:15px; --label:13px; } Now the app automatically scales beautifully on: Desktop Laptop iPad iPhone You never have to create separate font sizes for different devices. I actually think this is something we should build into Version 3 from the start. A proper design token system (typography, spacing, colours, animation timings) will make the app much easier to tweak as your design evolves. Instead of searching through hundreds of lines of CSS, you'll have a handful of variables that control the entire visual language.
